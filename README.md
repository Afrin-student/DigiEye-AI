## 📌 About The Project

DigiEye is a web-based application that allows users to draw digits on a canvas or upload digit images and analyze them through an interactive interface.

The project includes prediction tracking, analytics, downloadable reports, and mobile touch support.

---

## ✨ Features

✅ Draw Digits on Canvas

✅ Upload Digit Images

✅ Predict Digit

✅ Confidence Score Display

✅ Prediction History

✅ Analytics Dashboard

✅ Most Predicted Digit Tracking

✅ Clear History

✅ Download Report
